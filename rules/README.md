# 検出ルールと、これまでに測ったもの

このディレクトリは、kagiya の実行ファイルに内蔵する検出ルール（データだけ。YAML）です。
既定値や対応表は、記憶ではなく、実物のパッケージや配布物を検証用のコンテナに導入して測ったものだけを載せています。
各項目には、測ったイメージ（ダイジェストつき）と OS が、出典として書いてあります。

**この一覧は、ルールのデータから自動で作っています。手で編集しないでください。**
ルールを足したら、`KAGIYA_UPDATE_README=1 go test ./internal/ruleset -run TestRulesReadme` で作り直します。

ルールのバージョン: `2026.11.0`

## 暗号ライブラリが耐量子のアルゴリズムに対応している版

「対応」は、ライブラリがその方式を持っていることです（使う設定になっているかは別）。「確かめた範囲」の外の版は、前後から推定します。

| ライブラリ | 対象 | 方式 | 対応している版 | 確かめた範囲 | 根拠 |
|---|---|---|---|---|---|
| openssl | ライブラリ全体 | ML-KEM・ML-DSA・SLH-DSA・TLS-MLKEM・TLS-MLKEM-hybrid | 3.5.0 以降 | 3.0.13〜3.5.8 | 開発元の資料 |
| bouncycastle | bcprov-* | ML-KEM・ML-DSA・SLH-DSA | 1.79 以降 | 1.71〜1.87 | 実物で確かめた |
| bouncycastle | bctls-* | TLS-MLKEM | 1.80 以降 | 1.71〜1.87 | 実物で確かめた |
| bouncycastle | bctls-* | TLS-MLKEM-hybrid | 1.81 以降 | 1.71〜1.87 | 実物で確かめた |
| bouncycastle | bc-fips | ML-KEM・ML-DSA・SLH-DSA | 確かめた範囲では、対応していない | 1.0.0〜2.1.3 | 実物で確かめた |
| conscrypt | conscrypt-openjdk、conscrypt-openjdk-uber | ML-KEM・ML-DSA・SLH-DSA | 2.6.0 以降 | 2.6.0〜2.9.0 | 実物で確かめた |

方式の名前: `TLS-MLKEM` は TLS の ML-KEM 単独の鍵交換、`TLS-MLKEM-hybrid` は TLS のハイブリッドの鍵交換（X25519MLKEM768 など）です。

## ファイルの構成

| 場所 | 内容 |
|---|---|
| `manifest.yaml` | ルールの版 |
| `catalog/` | 暗号アルゴリズムの名前と別名（OID、OpenSSL の名前、SSH の名前など） |
| `policies/` | 評価の基準（量子計算機への耐性、古典的な安全性） |
| `apps/` | 対応しているソフトウェアの定義（設定ファイルの場所、読む項目） |
| `defaults/` | ソフトウェアの既定値（パッケージの版ごと） |
| `ciphers/`、`groups/` | OpenSSL の暗号スイートと鍵交換のグループの表（パッケージの版ごと） |
| `java/` | JDK、Tomcat、Spring Boot の表 |
| `libraries/` | 暗号ライブラリの見分け方と、耐量子のアルゴリズムに対応している版 |
| `os/` | パッケージの役割、証明書ストアの場所 |

# サンプルのスキャン結果

`kagiya scan` の結果（JSON）のサンプルです。GitHub Pages で公開しているサンプルのレポートは、ここにあるファイルから
`kagiya report` で作っています（`.github/workflows/pages.yml`）。

**実際のホストの結果ではありません。** 検証用のコンテナ（Docker 公式の Debian 13、Ubuntu 24.04、AlmaLinux 9 のイメージ）に、
ディストリビューションのパッケージ（OpenSSH、nginx、Apache httpd、Tomcat）を導入し、検証用の証明書と設定を置いたものをスキャンしました。

- ホスト名は、コンテナの ID です。
- 証明書は、OS に同梱されている公開の CA 証明書と、検証用に作った `lab.test` のものです。
- 一部のファイル（業務アプリの JAR、暗号ライブラリの JAR）は、名前だけの空のファイルです。ファイル名からライブラリと版を読むことを示すために置いています。

実際のホストをスキャンした結果には、鍵や証明書の場所、ネットワークの構成などが含まれます。機密として扱い、公開の場所には置かないでください。
